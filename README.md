# 🚀 CV-Website | Dimas Wijanarko

> **Modern, High-Performance Personal CV & Software Engineer Portfolio**  
> Built with Next.js 13 (App Router), React 18, TypeScript, Tailwind CSS, and BaaS Supabase.  
> Inspired by the award-winning **Bedimcode Bianca** design aesthetic with custom Syne & Poppins typography, rotating circular badge, living particle constellation, and interactive service accordions.

## 💻 Cara Menjalankan Secara Lokal

1. **Clone repositori:**
   ```bash
   git clone https://github.com/Dimss-W/CV-Website.git
   cd CV-Website
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Konfigurasi Environment Variables (Opsional untuk Supabase):**
   Salin `.env.example` ke `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
   Lalu isi `NEXT_PUBLIC_SUPABASE_URL` dan `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.

4. **Jalankan Development Server:**
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
